= Parallels and Apple Silicon to play with K8s

This is a multi-node Kubernetes cluster on Parallels and Apple Silicon. It uses the kubeadm tool to create the cluster.

* OS: Ubuntu 22.04 LTS (Jammy Jellyfish)
* Kubernetes: 1.34.6
* CNI: Calico v3.27.3
* Helm: v3.17.1
* 1 master node, 2 worker nodes

== Cluster Layout

[cols="3", options="header"]
|===
| Node | IP | Role
| kmaster | 10.37.129.100 | Control Plane
| kworker1 | 10.37.129.101 | Worker
| kworker2 | 10.37.129.102 | Worker
|===

Resources per node:

* kmaster: 4 CPUs, 12GB RAM
* kworker: 4 CPUs, 6GB RAM

== What Gets Installed Automatically

The bootstrap scripts provision the following on `kmaster`:

* Calico CNI (v3.27.3)
* Helm (v3.17.1)
* MetalLB (via Helm) — IP pool: `10.37.129.120–10.37.129.140`
* ArgoCD (via Helm, namespace: `argocd`)
* Helm repos: `traefik`, `metallb`, `argo`
* Traefik values file extracted to `/home/vagrant/traefik-values.yml`
* MetalLB config pre-generated at `/home/vagrant/metal-lb.yml`
* `kubectl` alias `k` added to `.bashrc`
* `bash-completion` for kubectl
* `git clone https://github.com/itlinux/ciaobella`

NOTE: Traefik is not installed by default. The Helm repo is added and the default values are available at `/home/vagrant/traefik-values.yml` for customization before install.

== Ciaobella Repo

The `ciaobella` repo is cloned automatically to `/home/vagrant/ciaobella` and contains:

* `rbac/` — Kubernetes RBAC roles, rolebindings, and kubeconfig setup for user `max`
* `cert-manager/` — cert-manager manifests including self-signed issuer and certificate
* `k8s` — contains a deployment and a service demo for the user max 
* And more...

== Getting Started

=== 1. Start the cluster

[source,bash]
----
vagrant up
----

=== 2. SSH into master

[source,bash]
----
vagrant ssh kmaster
----

=== 3. Apply MetalLB config

Review the IP pool range in the file, then apply:

[source,bash]
----
k apply -f metal-lb.yml
----

NOTE: Workers print a reminder to apply `metal-lb.yml` after joining. Wait a few minutes after `vagrant up` before applying.

=== 4. Verify cluster

[source,bash]
----
k get nodes
k get pods -A
----

== ArgoCD

ArgoCD is installed in the `argocd` namespace. Retrieve the initial admin password with:

[source,bash]
----
k get secrets -n argocd argocd-initial-admin-secret -o jsonpath="{.data.password}" | base64 -d
----

This command is also saved at `/home/vagrant/argo-pass-cmd` for convenience.

== Quick Demo

Run an nginx pod and expose it:

[source,bash]
----
k run nginx --image=nginx
k expose pod nginx --port 80 --type=LoadBalancer
k get svc
----

Then curl the assigned LoadBalancer IP from the `10.37.129.120–10.37.129.140` pool.

Or use port-forward directly:

[source,bash]
----
k port-forward nginx 8888:80 --address 10.37.129.100
curl http://10.37.129.100:8888
----

NOTE: On Apple Silicon (arm64), use arm64-compatible images. Tested with `nginx` and `arm64v8/httpd`.

== Traefik

Traefik is not installed by default. To install using the pre-added Helm repo:

[source,bash]
----
# Review and edit values first
vi /home/vagrant/traefik-values.yml

# Install
helm install traefik traefik/traefik -n traefik --create-namespace -f /home/vagrant/traefik-values.yml
----
